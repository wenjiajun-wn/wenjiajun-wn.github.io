部署 TabPFN API

目标：服务器接收表格数据，调用 TabPFN 在 GPU 上完成预测，然后把结果返回给客户端。

开始以为主要的就是装环境、FastAPI、启动 Uvicorn，但是部署后才发现，模型本身反而是最简单的一部分。更多问题出现在了 Python 环境、Hugging Face 权限、模型下载、端口冲突以及后台进程管理上。

总结成：

问题 原因 解决办法
TabPFN 权重下载失败 Hugging Face gated model 接受协议并配置 Token
Hugging Face 下载慢 网络问题 使用 Mirror
服务启动依赖外网 在线加载权重 提前下载本地模型
8000 无法启动 Chronos 已占用 TabPFN 使用 8001
SSH 关闭后服务消失 Uvicorn 前台运行 nohup
systemd 不可用 当前是容器环境 不使用 systemd
supervisorctl 异常 平台定制 Supervisor 不强行修改
Python 环境混乱 多套 Conda/Python 检查 which python
GPU 容易 OOM 多 worker 重复加载模型 --workers 1
