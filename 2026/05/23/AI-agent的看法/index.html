AI Agent 的看法

本文从个人理解出发，介绍 Agent 的基本构成，以及 ReAct 架构、TAO 循环两大重要理论和护栏机制在其中的作用。

1 什么是 Agent

我认为 Agent 主要就是一个可以进行思考、规划、使用工具，且执行行动后能从得到的结果中获取反馈的一个 AI：

Agent = LLM 大模型（类似大脑） + 规划的能力 + 能使用工具 + 行动的接口

  • 规划能力：可以将我们提出的复杂问题拆分成解决问题的每一个优先级步骤
  • 工具使用：能调用搜索引擎、API 等等外部的工具
  • 执行行动：在我们规划好的范围内，人为不进行干预，让 AI 自主完成实现代码的运行

2 重要理论

其中 Agent 有一些重要的理论，比如：ReAct 架构、TAO 循环。

2.1 ReAct 架构

ReAct 架构（reasoning + acting，推理加行动），就是让 AI 不只是拥有文本输出，而是像人一样边思考边行动。

2.2 TAO 循环

TAO 循环拥有三个主要的模块：Thought（思考）、Action（行动）、Observation（观测）

  • Thought（思考）：AI 接受到人类指令时，会进行思考然后计划下一步开始做什么，并且分析当前的状况，推理出需要的信息，最后决定采取什么行动
  • Action（行动）：AI 在思考中进行的决定，它会调用搜索工具，查询 SQL，或者进行计算，与外部进行互动
  • Observation（观测）：AI 接收并分析行动的反馈结果，如果结果不理想，循环就会再次启动，进行新一轮的思考-行动-观测

ReAct 架构的本质是推理-行动-观测三者的循环迭代。ReAct 架构的设计理念就是定义了一个让 AI 能够思考-行动-观测的行为模式。TAO 循环是实现 ReAct 的具体运转步骤，是这个模式的代称。

3 护栏（Guardrails）

护栏（Guardrails）：强大的 AI 需要设置安全的边界，防止 AI 失控。

react-cycle-guard：它正是 ReAct 循环与护栏概念在代码层面的结合，一个用来检测和防止 React 组件陷入无限渲染循环的护栏，而且能确保 UI 的稳定。

4 总结

总结：TAO 循环是让 AI 变”活”的运转模式，护栏是确保 AI 变”稳”的安全机制。
