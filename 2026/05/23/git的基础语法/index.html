git 的基础语法

本文整理 git 最常用的基础命令，涵盖目录查看、仓库初始化、暂存与提交、差异比较以及撤销与恢复，适合作为日常使用的速查参考。

1 基本操作

1.1 目录与版本查看

命令 说明
pwd 打印当前的工作目录
cd 移动到指定目录
ls 列出目录下的文件
git --version 查看 git 的版本
git status 查看当前仓库的状态
git log 查看提交历史
git log -2 仅查看最近两个提交的信息
git log --since 查看自某个日期以来的提交

1.2 初始化、暂存与提交

命令 说明
git init 初始化一个 git 仓库
git add . 只需一个命令，将两个修改过的文件添加到暂存区
git commit -m 提交变更，并在命令中附带日志消息

1.3 查看差异

命令 说明
git diff 查看文件的修改内容
git diff --staged 将最后提交的版本与暂存区的版本进行比较
git diff report.md 查看 report.md 文件的修改内容
git diff HEAD~1 HEAD~2 比较最近两次提交之间的差异

1.4 撤销与恢复

命令 说明
git revert 撤销一个提交
git checkout 切换分支或恢复工作树文件
git restore --staged 将文件从暂存区恢复到工作区
git revert HEAD --no-edit 撤销最近的提交，并使用默认的提交消息
